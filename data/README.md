# data/

## `samples/` — input documents

**Real bank statements** (used by `evaluation/bank_statement_agent_eval.py`,
`evaluation/baseline.py`, `models/qwen.py`'s manual tests):

| File | What it is |
|---|---|
| `bs1.pdf` | TemplateLab-style itemized statement, math discrepancy of £965.00 |
| `bs2.pdf` | BNI-style itemized statement, manually filled in by author — math discrepancy of −£150.00 |
| `bs3.pdf` | Bickslow Bank-style itemized statement, manually filled — dates swapped, no math error |
| `bs4.pdf` | First Citizens Bank-style itemized statement, manually filled — math discrepancy of −£1000.00, dates swapped |
| `bs5.pdf` | Stock "Bank Statement Example" image found online — clean (no injected errors) |
| `bank_statement_anomaly_word.pdf` | Hand-crafted HSBC-style statement (real text layer, not scanned) — math discrepancy of −£2186.69, dates swapped |
| `bank_statement_clean_word.pdf` | Hand-crafted SunTrust-style statement (real text layer) — clean, used as the "no anomaly" case in `evaluation/baseline.py` |

Full details (exact discrepancy amounts, which dates were swapped) are in
`bank_statements_ground_truth.json`, not repeated here to avoid the two drifting apart.

**Synthetic bank statements** (`synthetic/`) — generated by `../generate_synthetic_statements.py`,
a controlled 4-document set with precisely known injected errors (clean / math-only /
date-only / both), plus `synthetic/ground_truth.json`. See that script's own documentation
for what each one contains.

**Annual reports**: `goldman_sachs_2023-annual-report.pdf` and `jpmorgan_annualreport_2023.pdf`
— full public 10-K style filings, used for the SEC 10-K RAG evaluations
(`evaluation/sec10k_eval.py`, `evaluation/sec10k_agent_eval.py`). Their question/answer/oracle-page
ground truth lives in `../sec10k_qa.json` (39 hand-curated QA pairs across both companies), not
in this folder.

**The two similarly-named JSON files — don't confuse these:**

| File | What it actually is |
|---|---|
| `bank_statements_ground_truth.json` | Hand-labeled ground truth: a list of 6 entries (the real bank statements above) with the *actual* known math discrepancy / date-swap status — what the anomaly checker *should* find. |
| `bank_statements_extracted.json` | A cache of Qwen2-VL-max's *extracted* fields for 10 documents (produced by `../evaluation/extract_bank_statements_once.py`), keyed by file path — model *output*, not ground truth. Used by `evaluation/shap_anomaly_eval.py` so it doesn't need to re-call the API. |

## `sec10k_qa.json`

39 hand-curated question/answer/oracle-page triples for the two annual reports above,
used as ground truth by `evaluation/sec10k_eval.py` and `evaluation/sec10k_agent_eval.py`.
